Create a production-quality Executive Overview page for a PCI Data Flow Intelligence Platform.

Purpose:
The platform helps enterprise architects, PCI compliance teams, cybersecurity teams, and application owners understand how PCI cardholder data (PAN) propagates across systems, identify influential systems, prioritize tokenization efforts, and quantify PCI scope reduction opportunities.

The page should be optimized for decision-making, not just reporting.

=====================================================
SECTION 1: EXECUTIVE KPI SUMMARY
=====================================================

Display high-level KPI cards at the top.

Metrics:

1. Total Systems
   Description:
   Total applications present in the dependency graph.

2. PCI In-Scope Systems
   Description:
   Number of systems currently receiving, storing, processing, or transmitting PAN.

3. PAN Carrying Connections
   Description:
   Number of system-to-system integrations carrying PAN.

4. Primary PAN Sources
   Description:
   Systems identified as original sources of PAN.

5. Average Downstream Reach
   Description:
   Average number of systems impacted by a PAN source.

6. Current PCI Risk Score
   Description:
   Enterprise-wide PCI exposure score.

7. Potential Risk Reduction
   Description:
   Estimated percentage reduction if recommended tokenization candidates are implemented.

Each KPI should include:
- value
- trend indicator
- tooltip explanation

=====================================================

=====================================================

Display a large interactive graph.

Node Types:

Red:

Orange:

Green:
Out of Scope Systems

Blue:
External Systems

Edge Types:

Solid Line:

Dashed Line:
Inferred Relationship

Flow Indicators:

Red Arrows:
PAN Flow

Green Arrows:
CRN / Token Flow

Graph Capabilities:

- zoom
- pan
- search
- filter
- node selection
- path highlighting

When a node is clicked:

Display:
- system name
- business owner
- technology owner
- PCI status
- risk score
- upstream count
- downstream count
- PAN exposure count
